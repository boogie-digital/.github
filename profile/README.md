# Boogie

**Boogie Mail** is a native JMAP mail, calendar and contacts client for iPhone, iPad, Mac and Apple Watch,
tested on every release against Stalwart and Fastmail. Built in Swift, with no analytics and no telemetry.

- Website: [boogie.digital](https://boogie.digital/)
- App Store: [Boogie Mail](https://boogie.digital/go/appstore/)
- Help: [boogie.digital/support](https://boogie.digital/support/)

## jmapcli

[jmapcli](https://boogie.digital/cli/) is a free, native macOS command-line JMAP client: send, read, search and
sync mail from the terminal.

```sh
brew install boogie-digital/boogie/jmapcli
```
